# ステークホルダー管理 > 立ち上げ

## 超概算：【対客】担当者予算打診不可時の決済者確認

---

## 導入

### このスキルを身につけると、何が変わるか

「超概算：【対客】決済担当者に予算の打診」の流れで予算打診を試みたとき、うまくいかないケースが2つあります。

1. **現場担当者が「上には通せない」と決済者へのアクセスをブロックする**
2. **現場担当者が「予算は教えられない」「まだ未定」と予算額を開示しない**

どちらも「予算の打診ができなかった」状態です。この教材は、その2つのケースに対して、どう動くかを扱います。

このスキルを学ぶことで：

- 「打診不可」の2パターンを見極め、それぞれに適した対応ができる
- 現場担当者のメンツを守りながら、上位者への橋渡しを依頼できる
- 決済者に直接会えない場合でも、承認の記録を残す方法がわかる
- 予算を「教えてもらえない・未定」と言われた場合の引き出し方と対処がわかる

---

## 学習目標

このテキストを読み終えると、以下ができるようになります。

1. **「打診不可」の2パターン（アクセス不可・情報不可）を区別し、それぞれの背景と対応を説明できる**
2. **現場担当者を通じて決済者を確認し、橋渡しを依頼するための質問を具体的に実践できる**
3. **予算を教えてもらえない・未定と言われたときの引き出し方を実践できる**

### Section 1：「打診不可」の2パターンを理解する

**一言でいうと：「予算の打診ができなかった」には2種類ある。まず今どちらかを見極める。**

超概算の打診がうまくいかない状況には、根本的に異なる2つのパターンがあります。

| パターン | 状況 | 本教材での扱い |
|--------|-----|------------|
| **A：アクセス不可** | 現場担当者から予算情報は得られたが、「上には通せない」と決済者への接触を遮断される | Section 2〜3で扱う |
| **B：情報不可** | 現場担当者が「予算は教えられない」「まだ未定」と、予算情報そのものを開示しない | **Section 4で扱う** |

> **パターンBの対応はSection 4へ。**
> 予算情報が得られていない状態で概算資料を作ることは「予算→超概算」の原則に反します。
> まずSection 4の手順で予算情報を引き出してから、Section 2〜3に進んでください。

まずどちらのパターンかを確認してから対応に入ることが重要です。
混在している場合（現場担当者とは話せるが、決済者への接続も予算情報の開示もされない）は、**BをSection 4で先に解消し、予算情報が取れてからAをSection 2〜3で対処します。**

#### パターンA：「上には通せない」が起きる背景

**最初にやるべきことは、現場担当者に「敵」と見なされないことです。**

「上に通したい」というPMの動きを、現場担当者は「余計なことをする人」「私を飛ばして動くつもりか」と受け取ることがあります。
この不信感が生まれると、その後の協力が得られなくなります。
現場担当者に「同じ目的に向かっている同志」と認識してもらうことが先決です。

**決済担当者への確認を依頼するときの伝え方**

```
❌ やってはいけない伝え方：
「担当者さんだけでは最終判断が難しいため、上の方にも確認させてください」
→ 「あなたには判断能力がない」という意味に聞こえる。侮辱に感じる人もいる。

⭕ 自然な伝え方（1）：関心ごとが違うからこそ直接伝えたい
「担当者さんと決済担当者の方では、見ているポイントが少し違うと思うんです。
 私からも直接、経営的な観点でお伝えしたいことがあって。」

⭕ 自然な伝え方（2）：人伝では温度感が下がる
「人を介して伝わると、どうしても熱量が変わってしまうことがあって。
 担当者さんにご説明のご準備をお願いするのも申し訳ないので、
 私から直接ご説明させていただけませんか？」
```

「上には通せません」「まだそのタイミングではない」という反応には、さらにいくつかの背景があります。

| 背景 | PMが取るべき対応 |
|-----|--------------|
| **権限がない**：現場担当者が予算の議論に参加できる立場ではない | 「どなたがご判断されますか？」と確認する |
| **社内稟議がまだ**：上司への報告タイミングが決まっていない | 「いつ頃ご報告の予定ですか？」と聞く |
| **現場担当者の心理的防衛**：「PMに決済者と直接話されると自分の立場が危うくなる」という不安から接触を遮断している | 現場担当者の不安を解消することが先決。「あなたを通じて進めたい、一緒に準備したい」というスタンスを示し、決済者へのアクセスが現場担当者を飛び越えるためではないと伝える |
| **決済者の性格への配慮**：決済者が対応の難しい人物で、現場担当者を通さずに話すと関係や話が拗れると現場担当者が判断している | 現場担当者の判断を尊重する。「どう伝えれば伝わりやすいか」を現場担当者と一緒に考え、現場担当者経由で届く資料・情報の質を上げることに集中する |
| **超概算の目的を理解していない** | 「なぜ今の段階で概算が必要か」を説明する |

**実際の会話パターン：一緒にやる姿勢を見せる**

背景を踏まえたうえで、依頼を一方的に押し付けず「どれくらい一緒にやるか」の温度感を探りながら話を進めます。

```
「社内や決済担当者へ上申していく時に必要な資料があれば、一緒に作りますよ。
 どんな形だと社内で使いやすいですか？」

「全部お任せします、というのも難しいと思うので、
 どこまで私が動くと助かりますか？」
```

### Section 2：現場担当者を通じて「決済者が誰か」を確認する

**一言でいうと：「誰が承認するか」だけは、現場担当者を通じて最初に確認する。**

決済者に直接会えなくても、「誰が最終的に承認するのか」は把握しておく必要があります。
これがわからないまま進むと、後から「その人は聞いていない」という状況が必ず起きます。

#### 現場担当者への確認の仕方

「決済者を教えてください」という直接的な聞き方は、現場担当者によっては「社内のことを探っている」と感じさせることがあります。
代わりに、**プロジェクトを進めるために必要な情報として確認する**という文脈で聞きます。

```
確認の例（NG）：
「最終的な承認者は誰ですか？」
→ 「なぜそれを聞くのか」と警戒される可能性がある

確認の例（OK）：
「今回の概算をご説明した後、社内でのご判断はどのような流れで進みますか？
 どなたのご承認が必要になりますか？
 準備できることがあれば、事前にお伝えしたいと思いまして。」
→ 「あなたの社内手続きを支援したい」という文脈になる
```

この聞き方のポイントは、「承認者を知りたい」ではなく「あなたの社内説明を助けたい」というスタンスです。

---

### Section 3：現場担当者を「味方」にする技術

**一言でいうと：現場担当者が社内で説明しやすい材料を作ってあげる。それでも会えない場合は承認の記録で安全を確保する。**

現場担当者が「上に通せない」と言う理由の多くは、「上司に説明できる自信がない」ことにあります。
PMが現場担当者の「社内説明の準備」を手伝うことで、現場担当者は自然と橋渡し役になります。

#### 現場担当者が上司に説明しやすい資料を作る

```
現場担当者への提案：
「上司の方へのご報告に使っていただける、簡単な説明資料を
 1〜2ページで作成しましょうか？
 金額の根拠・前提条件・次のステップをまとめた資料があれば、
 社内でのご説明がしやすくなると思います。」
```

この提案には2つの効果があります。
- 現場担当者の負担を減らす（現場担当者に感謝される）
- PMが作成した資料が上司に届く（決済者への間接的なアプローチ）

#### 資料に含めるべき内容

| 内容 | 目的 |
|-----|-----|
| **プロジェクトの目的・解決する課題** | 「なぜやるか」を上司が理解できるようにする |
| **予算の確認（前提条件つき）** | 現場担当者から聞いた予算感と上限金額を記載する。前提条件（保守・性能テスト・総合テスト担当など）も合わせて明示し、前提が変わると金額も変わることを示す |
| **投資対効果（しない場合のリスク）** | 「やる価値があるか」を判断できるようにする |
| **次のステップと確認事項** | 「何を決めてほしいか」を明確にする |

「上司が判断するために必要な情報」を現場担当者と一緒に整理することで、現場担当者は「準備万端で上司に報告できる」という安心感を得ます。
なお、この資料の概算金額は**現場担当者から聞いた予算を上限として組み立てる**ことが前提です。予算情報が得られていない場合は概算金額の欄は入れず、まずSection 4で予算を確認してください。

#### それでも決済者に会えない場合の対処

上記を試みても現場担当者が「上には通せない」の姿勢を変えない場合は、最低限の確認と記録で安全を確保します。

**① プロジェクトを進めるリスクを伝える**

「誰も承認していない状態でプロジェクトを進めることのリスク」を、現場担当者に正直に伝えます。

```
伝え方の例：
「予算規模の合意がないまま次のフェーズに進むと、
 後から『想定と違う』という状況になりやすいです。
 PMとして、最低限、金額の目安についてご担当部門の上位の方に
 ご認識いただけると、双方にとって安心です。
 どのような形であればご調整いただけますか？」
```

**② 「承認タイミング」だけは合意する**

直接の承認が難しい場合でも、「いつ誰が承認するか」だけは確認します。

```
確認の例：
「今すぐのご判断は難しいと理解しています。
 ○月○日の取締役会でご報告いただける予定でしょうか？
 その際に使えるご説明資料を事前にお送りします。」
```

「いつ・誰が・どこで承認するか」が見えているだけで、PMはプロジェクトの計画が立てられます。

### Section 4：予算を教えてもらえない場合の対処

**一言でいうと：「教えてもらえない」は実はほとんどない。本当に決まっていないケースの見極めが重要。**

実務上、顧客が予算を「教えない」ケースはあまり多くありません。
多くの場合は以下のどちらかです。

| パターン | 見分け方 | 対処 |
|--------|---------|-----|
| **本当に未定** | 「まだ予算申請前で」「来期の話で」という発言がある | 超概算を根拠に予算申請を支援する。「この規模感であれば○○○万円を上限に予算を申請されることをお勧めします」 |
| **聞かれるまで言わない** | 検討段階なのに「予算は…」とはぐらかす | 「費用対効果・リスク」の切り口で聞き直す。「このシステムで解決したい課題にはどのくらいの価値がありますか？」 |

#### 教えてもらえないときに聞き直す言葉

```
「具体的な金額でなくて構いません。
 ○千万円台なのか、○億円台なのか、
 規模感だけでも教えていただけますか？

 その情報があると、私たちが提案できる内容の
 方向性が決まります。お互いの時間を
 無駄にしないためにも、ぜひ教えてください。」
```

### Section 5：「現場担当者とPMの関係」が鍵になる

**一言でいうと：現場担当者がPMを信頼しているほど、決済者への橋渡しはスムーズになる。**

現場担当者が「上に通せない」と言うとき、それはPMへの不信感が原因のこともあります。
「この人に予算の話をしたら、後で自分が困ることにならないか」という不安です。

#### 現場担当者の信頼を得るための行動

```
✅ やること：
・現場担当者の発言を議事録に正確に残す（「あなたの言葉を尊重している」という示し）
・現場担当者が社内で困らないように、共有する情報の粒度を一緒に決める
・「この金額は私が現場担当者さんを通して確認しました」という言い方をする

❌ やってはいけないこと：
・現場担当者を飛ばして上司に直接連絡する（現場担当者のメンツが潰れる）
・「現場担当者には話した」という既成事実を使って決済者に迫る
・「あなたには決める権限がないから」という言い方をする
```

現場担当者が「PMは自分の味方だ」と感じていれば、上司への橋渡しは自発的に行われます。
**現場担当者との関係構築が、決済者へのアクセスを開く鍵です。**

## まとめとネクストアクション

### 3つの重要ポイント

1. **「打診不可」には2パターンある。まず「アクセス不可」か「情報不可」かを見極める**
   A（アクセス不可）は「予算情報は取れたが決済者に会えない」、B（情報不可）は「予算情報そのものが取れない」。
   混在している場合は、先にB（Section 4）で予算情報を引き出してから、A（Section 2〜3）に対処する。予算情報なしに概算資料を作ることは「予算→超概算の原則」に反するため。

2. **パターンA（アクセス不可）は現場担当者を「味方」にすることで解決する**
   「社内説明資料を一緒に作る」という提案が最も効果的。
   それでも会えない場合は承認タイミングの合意で最低限の安全を確保する。

3. **パターンB（情報不可）は「本当に未定」か「言いたくない」かで対処が変わる**
   「本当に未定」なら超概算を根拠に予算申請を支援する。
   「言いたくない」なら規模感だけを聞く言葉に切り替え、費用対効果・リスクの切り口で引き出す。
