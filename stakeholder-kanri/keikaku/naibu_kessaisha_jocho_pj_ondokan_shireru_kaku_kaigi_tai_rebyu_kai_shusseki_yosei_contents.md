# ステークホルダー管理 > 計画

## 【内部】決済者／上長にPJの温度感を知れる各会議体／レビュー会への出席要請

---

## 導入

### このスキルを身につけると、何が変わるか

「上長に報告書を送っているのに、いざ問題が起きたら『そんな深刻とは思わなかった』と言われた」
「顧客との定例会の雰囲気を言葉で説明しても、上長にうまく伝わらない」
「問題が大きくなってから上長が出てきたが、状況把握に時間がかかって対応が遅れた」——

報告書や口頭の説明で「温度感」を伝えるには限界があります。
「温度感」とは、数字や文字では表しにくい現場の空気感——
顧客の満足・不満の表情、チームの士気、課題の緊迫度、議論の熱量——そうした感触です。
このスキルは、**決済者・上長が会議体やレビュー会に出席することで、プロジェクトの温度感を直接感じてもらう環境を、計画の段階から設計する**技術です。

このスキルを学ぶことで：
- 上長がプロジェクトの「本当の状態」を把握した上で支援・判断できる
- 「報告書の行間」にある温度感が上長に届くようになる
- 問題が起きたとき「上長も状況を知っていた」という状態を作れる
- 上長の出席が、顧客・チームへの「プロジェクト重視」のシグナルになる

---

## 学習目標

このテキストを読み終えると、以下ができるようになります。

1. **「温度感」が書面だけでは伝わらない理由を説明し、上長出席の意義を語れる**
2. **上長に出席を要請すべき会議体・レビュー会を選定できる**
3. **上長の時間を配慮しながら、出席要請を効果的に行える**

## 本編

---

### Section 1：「温度感」とは何か、なぜ報告書では伝わらないのか

**一言でいうと：報告書は「事実」を伝えるが、温度感は「現場の空気」。読んでわかるものではなく、感じるものだ。**

「プロジェクトの温度感」とは、以下のような情報です。

```
温度感の例：
  ・顧客との打ち合わせで、顧客の表情が硬い／柔らかい
  ・「問題ない」と言いながら、担当者の声のトーンが沈んでいる
  ・チームのメンバーが活発に発言しているか、沈黙が続いているか
  ・顧客が積極的に意見を出しているか、受け身になっているか
  ・課題一覧の言葉の背後にある「深刻さ」や「緊迫度」
```

これらは報告書の文字には現れません。
「課題：○○が未確定（担当：田中、期限：6/30）」という1行の背後に、
「もう3週間動いていない・顧客も困っている・このままだと納期が危うい」という緊張感があったとしても、文字では伝わりません。

**上長への報告書の限界：**

| 報告書で伝わること | 報告書で伝わらないこと |
|---------------|------------------|
| 進捗率・達成率 | チームの士気・疲弊度 |
| 課題件数・優先度 | 各課題の「実際の重さ」 |
| 顧客の意見・要望 | 顧客の不満・期待・信頼度 |
| スケジュール状況 | 「間に合いそうか」の感触 |

上長が「そんなに深刻だとは思わなかった」と言うとき、多くの場合PMは報告していたのに、温度感が届いていなかったのです。

---

### Section 2：上長が出席することで何が変わるのか

**一言でいうと：上長が「見る」だけで、PM・チーム・顧客の3方向に効果が生まれる。**

上長が会議体・レビュー会に出席することには、複数の効果があります。

#### ① 上長が「温度感」を直接把握できる

報告書を読むより、30分の打ち合わせに同席するだけで、上長はプロジェクトの状態を体感できます。
「顧客の表情」「チームの動き」「議論の質」を自分で感じることで、PMへの支援・判断の質が上がります。

#### ② 問題が起きたときの対応が速くなる

上長が定期的に現場を見ていれば、問題発生時に「状況の共有から」始める必要がありません。

```
上長が現場を知らない場合：
  問題発生 → PMが説明 → 上長が理解するまで時間がかかる
  → 対応の意思決定が遅れる

上長が現場を知っている場合：
  問題発生 → PMが「先週の定例で話していた○○の件です」と伝える
  → 上長がすぐに状況を把握し、即断できる
```

#### ③ 顧客・チームへの「本気度」のシグナルになる

上長が出席することは、顧客に「ベンダーとしてこのプロジェクトを重視している」というメッセージになります。
またチームメンバーにとっても「上長がプロジェクトに関心を持っている」という事実が、士気を高めます。

#### ④ 上長が「共同責任者」になる

上長が現場を知っている状態は、「問題が起きたとき上長が知らなかった」という状況を防ぎます。
PMが1人でリスクを抱えるのではなく、上長も「見ていた」という共同認識が生まれます。

---

### Section 3：どの会議体・レビュー会に出席を要請するか

**一言でいうと：「毎回来てほしい」は難しい。「この場だけは」という厳選が鍵。**

上長の時間は限られています。
すべての会議に出席を求めると負担になり、要請自体を断られます。
「ここだけは来てほしい」という場を計画フェーズで選定します。

#### 出席を要請すべき会議体・レビュー会の優先度

| 優先度 | 会議体・レビュー | 出席理由 |
|------|-------------|--------|
| ★★★ | **顧客との月次定例会（またはプロジェクト開始・終了時の節目）** | 顧客との関係・温度感を直接感じられる最重要の場 |
| ★★★ | **重要な意思決定が行われる打ち合わせ（スコープ確定・変更承認など）** | 上長が「決定に立ち会った」という記録になる |
| ★★ | **要件定義レビュー・設計レビューなど主要フェーズの区切り** | フェーズ完了の品質・温度感を上長が判断できる |
| ★ | **週次の進捗報告会** | 上長の負担が大きいため、特に重要な時期に限定する |

「最低でも月1回・重要な意思決定の場に1回」が現実的な目安です。

#### 選定の判断基準

```
出席を要請すべき会議の特徴：
  ✅ 顧客と対面で温度感が伝わる場
  ✅ 大きな意思決定が行われる場（後から「知らなかった」になりうる）
  ✅ プロジェクトの節目・フェーズ完了のタイミング
  ✅ 問題・リスクが顕在化している時期の定例会

出席要請を控える会議の特徴：
  ❌ 詳細な技術的議論が中心（上長が判断できない内容）
  ❌ PMが単独で対応できる日常的な業務連絡
  ❌ チーム内部の作業調整（上長が入ることで話しにくくなる）
```

---

### Section 4：出席要請の「仕方」——上長が参加したくなる伝え方

**一言でいうと：「来てください」ではなく「あなたがいることで、こういう価値がある」と伝える。**

上長への出席要請は、「参加させてほしい」という一方的な依頼ではうまくいきません。
「上長がいることで何が変わるか」を具体的に伝えることが重要です。

#### 出席要請の構成

```
① なぜこの会議に出席してほしいか（目的）
② 上長がいることで何が変わるか（効果）
③ どれくらいの時間・頻度か（負担の明示）
④ 何を見てほしいか・何をしてほしいか（役割の明確化）
```

#### 出席要請の例文

```
【顧客月次定例会への出席要請】

「来月の顧客定例会（○月○日 14:00〜15:00）に
 ご同席いただけますか？

 目的：要件定義フェーズに向けて顧客の期待感・
     関心の温度感を上長に直接感じていただきたいためです。

 上長にいていただくことで：
 ・顧客に「このプロジェクトを重視している」というシグナルになります
 ・私が言葉で説明できない顧客の雰囲気を直接ご確認いただけます

 ご役割：冒頭の挨拶と、全体を通じての観察をお願いします。
      特に発言は不要です。30分でも構いません。

 事前に5分だけ状況をご説明させていただけますか？」
```

**ポイント：「発言は不要・○分だけでOK」という言葉が出席ハードルを下げる。**
上長が「自分が何かしなければいけない」と感じると、出席を負担に感じます。
「観察するだけでよい」「一部だけでよい」という選択肢を示すことで、要請が通りやすくなります。

---

### Section 5：出席後に「上長の所感」を引き出す

**一言でいうと：出席してもらった後の「フィードバックの場」を設けることで、出席の価値が倍になる。**

上長が出席した後、「どう感じたか」を聞く場を設けます。
これが次の出席への動機づけになり、また上長の視点からプロジェクトを見直す機会になります。

```
出席後のフィードバック確認（5〜10分）：

・「今日の打ち合わせ、いかがでしたか？」
・「顧客の反応・温度感はどう見えましたか？」
・「気になった点・私が見落としていそうなことはありますか？」
・「次回も同様に同席いただけますか？」
```

上長から「○○さんの発言が少ないのが気になった」「顧客の表情が少し硬かったように見えた」という気づきが返ってくることがあります。
PMが見えていなかった「別の視点」が得られる場になります。

また、上長が「来てよかった」と感じることで、継続的な出席への意欲が生まれます。

## まとめとネクストアクション

### 3つの重要ポイント

1. **「温度感」は報告書では伝わらない。上長に現場を見てもらうことが最速の理解促進**
   顧客の表情・チームの士気・議論の緊張感——これらは言葉で説明しても伝わりにくい。
   30分の同席で上長が得る情報は、10枚の報告書を超えることがある。

2. **出席要請は「全会議」ではなく「ここだけ」と厳選する。上長の時間を守ることが長続きの条件**
   顧客月次定例・重要な意思決定の場・フェーズ節目のレビューを優先する。
   「発言不要・○分だけでOK」と伝えることで出席ハードルを下げる。

3. **出席後に「所感を聞く5分」を設ける。上長の視点が、PMの見落としを補う**
   「どう見えましたか？」という一言が、PMが気づけなかった温度感の情報をもたらす。
   フィードバックを受け取ることが、次の出席への動機づけにもなる。
