# 継続案件の確認

## 確認テスト

**Q1. 継続案件において、最も避けるべき「危ない言葉」はどれですか？**

A) 「今回の変更点は何でしょうか？」

B) 「前回と同じで進めれば大丈夫ですよね」

C) 「契約書の内容を再確認させてください」

**Q2. 相手の担当者が変わった際、真っ先に行うべきことは何ですか？**

A) 以前の担当者との「阿吽の呼吸」がそのまま通じると信じる

B) これまでのルールや役割分担を、改めて資料で提示し合意を得る

C) 相手から連絡が来るまで、自分の判断で作業を進める

**Q3. プロジェクト計画書に「差分一覧（前回との違い）」を書く最大のメリットは何ですか？**

A) 作業範囲を明確にし、無償での追加作業や認識ズレを防ぐため

B) 自分の作業時間を増やすための言い訳を作るため

C) 契約書のページ数を増やして、仕事をしている感を出しため

---

## 👉 **正解を確認する Q1: [ B ] / Q2: [ B ] / Q3: [ A ]**

### 【解説】

#### Q1：思い込みの排除

正解は **B** です。
「前回と同じ」という前提は、仕様の曖昧化やリスクの見落としを招きます。プロは常に「変化」に敏感であるべきです。

* **ポイント：** 継続案件こそ「新案件」のつもりで挑むのが、事故を防ぐコツです。

#### Q2：認識のリセット

正解は **B** です。
人が変われば、判断基準もルールも変わります。過去の経緯を知らない新しい担当者に対し、改めて「私たちのルール」を言語化して共有することが不可欠です。

* **ポイント：** 担当変更は、契約条件を見直す絶好のチャンスでもあります。

#### Q3：責任の明確化

正解は **A** です。
継続案件では、善意で行った「ついで対応」がいつの間にか「当たり前の業務」になりがちです。差分を明確にすることで、どこまでが契約範囲かを守ることができます。

* **ポイント：** 「前回はサービスでやりましたが、今回は範囲外です」と言える勇気が、チームを守ります。
