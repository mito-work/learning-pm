# 【PJ計画作成】課題管理計画

## 確認テスト

**Q1. プロジェクトにおける「課題」の正しい定義はどれですか？**

A) すでに発生してしまい、作業が止まっているトラブルのこと。

B) 将来的に問題になる可能性がある、現時点での懸念事項のこと。

C) 打ち合わせの議事録に書かれた、単なる決定事項のこと。

**Q2. 課題管理表を作るとき、最も「やってはいけないこと」はどれですか？**

A) 「誰が担当か」を決めずに、保留のまま載せておく。

B) 優先度の低い課題であっても、IDを振って管理する。

C) 課題が解決した理由（経緯）をメモ欄に残しておく。

**Q3. 課題管理を成功させるための「運用のコツ」として適切なものはどれですか？**

A) 課題が100個以上たまるまで、リーダー一人で抱え込む。

B) 毎日、課題の内容を書き換えて、過去の履歴は消去する。

C) 定例会議などの決まった時間で、定期的に進捗を確認する。

---

## 👉 **正解を確認する Q1: [ B ] / Q2: [ A ] / Q3: [ C ]**

### 【解説】

#### Q1：未来のトラブルを予見する

**正解：B**
「すでに起きていること」は「障害（トラブル）」です。課題は「このままだとマズいぞ」という**未来の予測**です。この時点で手を打つことで、PJの成功率が格段に上がります。

* **ポイント：** 課題は「予防」、障害は「治療」と覚えましょう。

#### Q2：責任の所在を曖昧にしない

**正解：A**
「誰がやるか」が決まっていない課題は、100%放置されます。たとえ検討中であっても「一旦Aさんが預かる」という**ボールの持ち主**を明確にすることが、実務では極めて重要です。

* **ポイント：** 「担当者：チーム全員」は、実質「担当者：なし」と同じです。

#### Q3：リズムを作って放置を防ぐ

**正解：C**
課題管理表は、作ることよりも**「更新し続けること」**が何倍も難しいです。週1回の定例会などで強制的に見直す時間をセットにすることで、初めて管理が機能します。

* **ポイント：** 「課題管理表の更新」を、歯磨きと同じくらいルーチン化しましょう。
