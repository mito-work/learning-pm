# ドキュメント形式／作成ツール確定

## 確認テスト

**Q1. ドキュメントの「形式」を統一する最大のメリットはどれですか？**

A) 資料がカラフルになり、見た目が楽しくなる。

B) 読み手の確認ポイントが揃い、レビューや引継ぎの効率が上がる。

C) ページ数を増やすことができ、仕事をした気分になれる。

**Q2. ツール選定において、最も避けるべき状態はどれですか？**

A) 「Word」と「Google Docs」のように、同じ用途のツールがルールなく混在している。

B) 誰もが同時に編集できるツールを使っている。

C) 修正した人の名前が自動的に残るツールを使っている。

**Q3. 版数管理のルールとして、適切な運用はどれですか？**
A) 修正したら「最新版_修正1_佐藤」のように、日本語で名前を足していく。

B) 重要な承認を得る前の、書きかけの資料は「v1.0」とする。

C) 正式に承認された最初のバージョンを「v1.0」とし、以降の修正は数字を増やす。

---

## 👉 **正解を確認する Q1: [ B ] / Q2: [ A ] / Q3: [ C ]**

### 【解説】

#### Q1：チームの「目」を揃える

**正解：B**
形式がバラバラだと、読み手は毎回「この資料はどう読めばいいのか」という構造の理解から始めなければなりません。形式を揃えることは、チーム全体の脳の疲れを最小限にすることです。

* **ポイント：** 「迷わせない」のが一流のドキュメント設計です。

#### Q2：情報の「分散」はミスの源

**正解：A**
ツールが混在すると、「本当の最新はどっち？」という確認作業が発生します。これは「情報崩壊」の第一歩です。選定理由を明確にし、チームで1つのツールに絞ることが重要です。

* **ポイント：** ツール移行には大きな手間がかかるため、最初に決めるのが鉄則です。

#### Q3：数字で状態を語る

**正解：C**
「最新」「最終」といった言葉は、次の修正が入った瞬間に嘘になります。絶対的な「数字（バージョン番号）」で管理し、v1.0を一つの区切り（確定版）とすることで、混乱を防ぎます。

* **ポイント：** 口頭での修正指示を禁止し、必ずドキュメントに反映して版数を上げる文化を作りましょう。
