# 機密情報の破棄

## 確認テスト

**Q1. プロジェクト終結時、すべてのデータを一律に完全削除することの弊害として、最も適切なものはどれですか？**

A) 情報漏えいのリスクが高まってしまう。

B) 次のプロジェクトで同じ失敗を繰り返したり、見積精度が上がらなくなったりする。

C) サーバーの容量が空きすぎて、管理コストが逆に増えてしまう。

**Q2. 「自社の資産」として残すべき情報として、適切なものはどれですか？**

A) 顧客から預かったシステムのパスワードやアクセスキー。

B) 顧客企業の担当者の個人名が含まれた連絡先リスト。

C) 失敗したトラブルの事例を、顧客名がわからないように一般化したレポート。

**Q3. 契約書に「機密情報の破棄」と記載がある場合の正しい解釈はどれですか？**

A) 自分の頭の中にある記憶も含めて、その仕事に関する一切を忘れるべきである。

B) 顧客に不利益を与える「顧客固有の情報」は確実に消すが、得られた「知見や汎用的な型」は加工して残して良い。

C) 契約違反になるのが怖いので、自社で作ったテンプレートやプログラムも全て消去すべきである。

---

## 👉 **正解を確認する Q1: [ B ] / Q2: [ C ] / Q3: [ B ]**

### 【解説】

#### Q1：組織の成長を止めないための終結

正解は **B** です。
全てを消すと、せっかく得た「学び」まで消えてしまいます。Aは削除することでむしろリスクは下がるため間違い、Cは論理的ではありません。

* **ポイント：** 破棄は「作業」ではなく、次への「投資」と捉えましょう。

#### Q2：知見を資産に変える「抽象化」

正解は **C** です。
AやBは「顧客固有機密」であり、持っているだけでリスクになります。Cのように、特定の誰かを指さない形（匿名化・抽象化）にすることで、初めて会社の資産になります。

* **ポイント：** 「具体的な数値」を「10〜20%の範囲」のようにレンジ化するのも有効なテクニックです。

#### Q3：契約の真意を理解する

正解は **B** です。
顧客が守りたいのは「自社の秘密」であり、あなたの「スキルアップ」を邪魔することではありません。Aは現実的ではなく、Cは自社の成長機会を損失しています。

* **ポイント：** 「顧客の利益を守りつつ、自社の知恵を増やす」のがプロのバランス感覚です。
