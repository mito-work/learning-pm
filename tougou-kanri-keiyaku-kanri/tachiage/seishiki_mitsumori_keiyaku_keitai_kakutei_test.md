# 正式見積：【対客】契約形態確定

## 確認テスト

**Q1. まだ何を作るか決まっていない顧客に対し、予算感を聞かれた際の正しい対応は？**

A) 期待に応えるため、正確な金額を算出し「請負」で提示する。

B) 誤差があることを前提に、ROM（超概算）として提示する。

C) 金額は一切伝えず、要件が固まるまで見積を拒否する。

**Q2. 「作りたいものはあるが、詳細な仕様は相談しながら決めたい」という顧客に最適な契約形態は？**

A) 準委任（作業時間に対して対価をもらう）

B) 請負（完成品に対して対価をもらう）

C) どちらでも問題ない

**Q3. 見積において「PMBOK（プロジェクト管理の標準）」が最も重視している視点は？**

A) 1円単位まで正確に計算すること

B) 競合他社よりも安い金額を提示すること

C) どこまで約束し、どこから約束しないかの「責任範囲」を確定させること

---

## 👉 **正解を確認する Q1: [ B ] / Q2: [ A ] / Q3: [ C ]**

### 【解説】

#### Q1：概算の重要性

正解は **B** です。
要件が曖昧な時期に確定金額を出すと、後で仕様が変わった際にトラブルになります。「現時点ではこの程度の規模感」と範囲（±50%など）を持たせて伝えるのがプロの技術です。

* **ポイント：** 「ROM」という言葉を使い、確定ではないことを合意しましょう。

#### Q2：柔軟な契約の選択

正解は **A** です。
仕様を相談しながら決める場合、B（請負）にすると「変更のたびに追加費用」が発生し、顧客との関係が悪化します。A（準委任）であれば、柔軟に内容を変えながら進められます。

* **ポイント：** 迷ったら「まずは準委任で要件定義」が鉄則です。

#### Q3：見積の本質

正解は **C** です。
見積は単なる「計算」ではなく「合意」です。契約形態を選ぶことは、万が一の時に「どこまでが自分の責任か」を明確にすることに他なりません。

* **ポイント：** 見積書を出す前に「契約の条件」をセットで考えましょう。
