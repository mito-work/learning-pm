# 正式見積：【対客】見積からのスコープ／スケジュール／工数／金額調整

## 確認テスト

**Q1. 見積提示後に顧客から「予算オーバーだ」と言われた時、最初に見直すべき項目は何ですか？**

A) 利益率を削って、金額だけを下げる。

B) バッファ（予備工数）をすべて削除して調整する。

C) スコープ（実施内容）を見直し、必須機能に絞り込む。

**Q2. 納期の前倒しを強く依頼された際、PMとして取るべき「正しい交渉」はどれですか？**

A) 「気合で頑張ります」と答え、メンバーに増員なしで残業を依頼する。

B) 「前倒しする場合、貴社での確認・承認作業も◯日早めていただく必要があります」と条件を提示する。

C) 工数を無理やり削減し、テスト工程を短縮して間に合わせる。

**Q3. 調整後のトラブルを防ぐために、最も効果的な行動はどれですか？**

A) 仲良くなって、信頼関係だけで進める。

B) 打ち合わせの録音を自分だけで持っておく。

C) 「今回の対象外事項」を含めた合意内容を、文章（メール等）で送り、承認を得る。

---

## 👉 **正解を確認する Q1: [ C ] / Q2: [ B ] / Q3: [ C ]**

### 【解説】

#### Q1：正しい調整の入り口

正解は **C** です。
金額だけを下げると、作業量は変わらないため必ず現場が疲弊します。まずは「作るもの」を減らすことが、健全なコスト削減の第一歩です。

* **ポイント：** 削る＝手抜きではなく、「優先順位の整理」と捉えましょう。

#### Q2：リソースと条件の交換

正解は **B** です。
スケジュールを短縮するには、作業を並列化するか、待ち時間を減らすしかありません。顧客側の協力（早期承認など）を条件に出すのがプロの交渉です。

* **ポイント：** 「早めるなら、そちらも早めてね」というギブ・アンド・テイクを成立させます。

#### Q3：証拠による防衛

正解は **C** です。
「やること」の合意と同じくらい「やらないこと（対象外）」の合意は重要です。これを書かないと、後から「これもやってくれると思ってた」と言われる隙を与えます。

* **ポイント：** 文面で残すことは、自分だけでなく顧客を守ることにも繋がります。
