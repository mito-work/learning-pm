# 正式見積：【内部】PLや有識者への機能見積依頼

## 確認テスト

**Q1. PMが内部で見積を依頼する「最大の目的」は何ですか？**

A) 現場のエンジニアに作業量を自覚させるため

B) 会社として「守れる約束」ができるか判断する材料を集めるため

C) とにかく安い工数を出させて、顧客への価格を下げるため

**Q2. 見積を依頼する際、精度の高い回答をもらうために「最も重要」なことは何ですか？**

A) 「とりあえず概算で」と気楽に依頼する

B) 「やること」だけでなく「やらないこと（対象外）」を明確にする

C) 締め切りを当日中に設定して、集中して計算してもらう

**Q3. PLから見積が返ってきた後、PMが取るべき行動として適切なものはどれですか？**

A) 予算を超えていたので、PLに相談せず一律20%工数を削って顧客に出す

B) 数字だけを信じて、そのままの内容で顧客に正式見積書を送る

C) 「一番リスクが高いのはどこか？」をPLに聞き、不確実な点を確認する

---

## 👉 **正解を確認する Q1: [ B ] / Q2: [ B ] / Q3: [ C ]**

### 【解説】

#### Q1：見積は「判断」のための武器

正解は **B** です。見積は単なる数字の計算ではなく、リスクを洗い出し、ビジネスとして成立するかを「判断」するためのものです。AやCのような意識だと、プロジェクトは必ずどこかで破綻します。

* **ポイント：** PMの役割は「予算を守ること」ではなく「約束を守ること」です。

#### Q2：境界線を引くのがPMの仕事

正解は **B** です。見積もる側が一番困るのは「どこまでやるか曖昧なこと」です。対象外を明記することで、PLは余計な心配をせずに計算に集中できます。AやCは、後から「そんなの聞いてない」というトラブルを招く原因になります。

* **ポイント：** 「何をやらないか」を決めるのが、見積精度のプロです。

#### Q3：数字の裏にある「声」を聴く

正解は **C** です。PMの腕の見せ所は、返ってきた数字をどう扱うかです。リスクの高い場所を知っておけば、顧客に対して「ここには予備の時間が必要です」と論理的に説明できます。Aの勝手な削減は、炎上への特急券です。

* **ポイント：** 削るなら「工数（時間）」ではなく「機能（作るもの）」を削りましょう。
